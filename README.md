# CHASE 404
3D 멀티플레이 술래잡기 프로토타입입니다.

## 로컬 실행
Node.js 설치 후:
npm install
npm start
브라우저에서 http://localhost:3000

## Render
GitHub에 이 폴더를 올린 뒤 Render Web Service로 배포하세요.
Build Command: npm install
Start Command: npm start

Render는 PORT를 자동으로 제공하므로 포트를 직접 만들 필요가 없습니다.

## 조작
WASD 이동, 마우스 시점 회전.
방 코드를 비우면 새 방을 만들고, 같은 코드를 입력하면 같은 방에 들어갑니다.
